# Tailscale Routing 1.0.0 — Compact

Отдельное приложение Windows x64 для исключений маршрутизации Tailscale, выделенное из Switcher 1.1.0.2. Не требует Zapret и не управляет его службой.

## Оформление

Компактное окно 740 × 470 в стиле баннера: тёмно-синий фон, голубые акценты, девять светящихся точек, версия 1.0.0 и подпись pb_coder. Минимальный размер — 700 × 430. Журнал свёрнут по умолчанию; нажмите «Журнал», чтобы раскрыть его. При ошибках он открывается автоматически. Перемещение правил, набор .ru / .рф / .su и помощь доступны в меню «Ещё».

## Запуск

Распакуйте всю папку Windows в доступное для записи место. Запустите **Tailscale Routing.exe** и подтвердите системный запрос администратора: права нужны для временного сетевого адаптера и правил Windows. Установка и перезагрузка не требуются. Требуется .NET Framework 4.7.2 или новее.

1. В официальном Tailscale подключитесь и выберите работающий exit node.
2. Добавьте сайты, IP/подсети или имена программ EXE, которые должны идти напрямую.
3. Нажмите «Сохранить», затем «Включить». Остальной интернет-трафик пойдёт через exit node.

Можно импортировать списки TXT, LIST, JSON, CSV, в том числе routing.json из Switcher через кнопку «Импорт…». Старые настройки автоматически не изменяются и не переносятся. Поддерживается до 2000 правил. Домены включают поддомены, правила программ применяются по имени EXE.

## Значок и управление

Девять точек без букв. Синее неоновое свечение точек в окне, на панели задач и в трее означает, что временный туннель включён и движок работает. При остановке или обнаруженном обрыве точки становятся серыми. Проверка сети выполняется периодически, поэтому значок не является мгновенным индикатором доступности каждого сайта.

Крестик и сворачивание скрывают окно в трей. Двойной щелчок по значку открывает окно. Меню значка позволяет включать/останавливать правила и завершать приложение. «Выход» останавливает собственный движок и удаляет временные сетевые разрешения; официальное подключение Tailscale остаётся включённым. После потери сети восстановите соединение и нажмите «Включить» повторно. Автозапуска и автоматического включения правил нет.

Настройки и журнал: `%LOCALAPPDATA%\TailscaleRouting`. Встроенный движок извлекается в папку Engine рядом с EXE и проверяется по SHA-256. Удаление приложения: выберите «Выход» и удалите распакованную папку; при необходимости отдельно удалите папку настроек.

## Ограничения

Один активный интернет-интерфейс с IPv4-шлюзом. Режим IPv4, унаследованный от исходного проекта; обычные IPv6-соединения через временный туннель блокируются для перехода приложений на IPv4. Не запускайте маршрутизацию Switcher одновременно: Tailscale Routing обнаруживает его активный адаптер перед стартом. Приложение не является официальным продуктом Tailscale.

## Исходники и сборка

В папке Source находится только приложение маршрутизации. Запустите `powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1`. Сборка использует системный компилятор .NET Framework x64. Загрузка из сети не требуется: архив движка взят из предоставленной сборки Switcher. Исходники и лицензии sing-box сохранены в Engine. Изображения значка создаются собственным кодом BrandIcons.cs.
